# 3D 地図→Nav2 接続読本 — 点群の世界から占有格子の世界への翻訳

GLIM が作るのは 3D の点群地図、Nav2 が食べるのは 2D の占有格子地図 — この 2 つは
データ形式が違うだけでなく「世界の表現方法」が違う。点群は「どこで反射があったか」の
記録であり、占有格子は「どこが通れるか」の判定である。本書はこの翻訳層 —
3D→2D 地図変換・3D 点群の /scan 化・AMCL による自己位置 — の仕組みを、
「なぜ高さで切るのか」「なぜ帯を揃えないと自己位置が暴れるのか」まで下ろして解説する。
reRoBot では 2026-08-17 にこの接続層を実装した (実機での AMCL 通し検証は未)。

## 読み方

- **初読は 1 → 2 → 3 → 4 章を順に**。第 3・4 章の「帯整合」の議論は
  第 1 章の 3 入力モデルと第 2 章の占有格子の語彙を使う
- **今すぐ地図を変換したいなら第 7 章** — コマンドだけ並べてある。仕組みは後から
- **「AMCL がなぜ動くのか」から入るなら第 4 章** — 本書の中核
- 3D 地図そのものの品質 (z ドリフト・縦角) は [GLIM 読本](../glim/00_index.md) が正。
  2D SLAM 側は [slam_toolbox 読本](../slam_toolbox/00_index.md)、
  オドメトリ融合は [EKF センサ融合読本](../ekf_fusion/00_index.md) と分担する
