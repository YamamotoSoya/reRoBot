# ROS 2 C++ 構造読本 — reRoBot の実コードで学ぶ、C 経験者のための C++

ROS 2 のノードが読めないのは、C++ の全部を知らないからではない。
ROS 2 のアプリケーションコードが使う C++ は、**クラスと継承・名前空間・所有権 (RAII)・
コールバック束縛・spin (イベントループ) という 5 つの機構が固定の型で組み合わさった、
ほぼ 1 パターン**である。その型を知らないまま 1 行ずつ英単語のように訳すから迷子になる。
そして読めないコードは「動いているから」と手つかずのまま理解の空白になり、いざ壊れた
とき原因を語る言葉がなくなる — 本プロジェクトでも、初期化のレースを「動くか動かないかは
確率」と呼ぶしかなかった時期があった ([第6章 事例A](06_case_studies.md))。
本書は C の知識を足場に 5 つの機構を積み上げ、reRoBot の自作 C++ 全 3 ファイル
(計 1,072 行) を「全部読める」状態にすることを目標にする。

## 読み方

- **初読は第1章 → 第5章を順に**。クラスという器 (第1章)、名前の読み方 (第2章)、
  持ち方 (第3章)、渡し方 (第4章)、動かし方 (第5章) の順で積み上がる。
- 「なぜこんなことを学ぶ必要があるのか」を先に体感したければ、[第6章](06_case_studies.md) の
  事例A (片輪が動かない) から読み始めてよい。必要な前提には章リンクを張ってある。
- **いま目の前に読めない記法があるなら** [第7章](07_reference.md) の記法逆引き表から
  該当章へ飛ぶのが最短。
