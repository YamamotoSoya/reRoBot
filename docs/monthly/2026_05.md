# 2026 年 5 月 — 2D LiDAR (HOKUYO) 統合と slam_toolbox で地図を作れるまで

| 名前 | 説明 |
|---|---|
| **HOKUYO 2D LiDAR の統合 (05-03〜05-05)** | UTM-30LX を `urg_node` で動かし、URDF に `laser` フレームを足して SLAM 入力を用意 |
| ├─ Dockerfile に urg_node / slam_toolbox 追加 + URDF laser 追加 | `ros-jazzy-urg-node` `ros-jazzy-slam-toolbox` を apt 追加 (現 [Dockerfile_main](../../docker/Dockerfile_main))、`rerobot.urdf` に laser link/joint ([rerobot.urdf](../../ros2_ws_main/src/bringup/rerobot_bringup/urdf/rerobot.urdf))。`5fefe57` |
| ├─ ハード手順を README に追記 / 左右反転 / laser フレーム名 | `invert_left/right: true` に変更 (実配線の回転方向合わせ)、URDF の `laser_frame` → `laser`、[README.md](../../README.md) に CAN/HOKUYO の接続手順。robot_state_publisher は一時コメントアウト。`2b0194d` |
| ├─ robot_state_publisher 再有効化 | `/joint_states` を epos4_odometry が直接出すので remap 不要と整理し、RViz に車輪 TF・odom・(後の) particle を表示できるように。`6fc95b6` |
| └─ urg_node を bringup launch に組み込み + slam.launch.py 新設 | `serial_port` 引数 (既定 `/dev/ttyUSB-utm-30lx`)、frame_id `laser`、±90° で `/scan` を出す。slam_toolbox 用 `slam.launch.py` + `slam_toolbox.yaml` を追加 (現 [slam.launch.py](../../ros2_ws_slamtoolbox/src/rerobot_slamtoolbox/launch/slam.launch.py), [slam_toolbox.yaml](../../ros2_ws_slamtoolbox/src/rerobot_slamtoolbox/config/slam_toolbox.yaml) — 07-26 に slamtoolbox ws へ分離)。lifecycle の CONFIGURE→ACTIVATE は launch 側 EmitEvent で発火。`e602f54` |
| **bringup 資産の分離 `rerobot_bringup` (05-04)** | launch / config / urdf / rviz を C++ パッケージ `epos4_controller` から launch-only パッケージへ移動 — 「app (C++) と bringup (資産) を分ける」現行構成の起点 |
| └─ rerobot_bringup パッケージ新設 | CMakeLists/package.xml を作り 4 資産を移動、[CLAUDE.md](../../CLAUDE.md) のパス記述を追従 (現 [rerobot_bringup/](../../ros2_ws_main/src/bringup/rerobot_bringup))。`1e034ef` |
| **slam_toolbox 「queue is full」問題の解決 (05-26〜05-28)** | `/scan` 40 Hz と odom TF 20 Hz のレート差で `scan_queue_size` 既定 1 が即溢れ、全 scan が drop されて地図が出なかった。詳細 [report 05-26](../report/2026-05-26_slam_toolbox_scan_queue_full.md) (PDF 版 [同](../report/2026-05-26_slam_toolbox_scan_queue_full.pdf) は 06-05 に追加) |
| ├─ slam_toolbox.yaml に scan_queue_size: 10 / transform_timeout: 0.5 | 意図的な設定値 (勝手に戻さない)。[slam_toolbox.yaml](../../ros2_ws_slamtoolbox/src/rerobot_slamtoolbox/config/slam_toolbox.yaml)。`33af0a0` |
| └─ debug-report skill の新設 | 解決済みバグを `docs/report/` に残す運用を開始 ([SKILL.md](../../.claude/skills/debug-report/SKILL.md), [template.md](../../.claude/skills/debug-report/template.md))。同コミットで 05-26 レポートを追加 (調査 05-26、コミット 05-28)。`33af0a0` |
