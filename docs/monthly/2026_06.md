# 2026 年 6 月 — 片輪不動の根治・Nav2 自律走行成功・R-Fans-16 3D LiDAR の立ち上げ

| └─ 05-26 レポートの PDF 版追加 | ゼミ資料用 ([PDF](../report/2026-05-26_slam_toolbox_scan_queue_full.pdf))。`957b7c0` |

| ├─ motor index ↔ 物理車輪の対応修正 | controller / odometry / teleop の 3 箇所で左右を入れ替え ([epos4_odometry.cpp](../../ros2_ws_main/src/app/epos4_controller/src/epos4_odometry.cpp))。`8ca003c` |
| └─ gear_ratio を 1.25 に (対症療法) | 実測 78.55 rad/10 回転 = 2.5π/回転 から逆算 (bringup 側 1.0→1.25、teleop 側 0.2→1.25、[params.yaml](../../ros2_ws_main/src/bringup/rerobot_bringup/config/params.yaml), [teleop params.yaml](../../ros2_ws_main/src/app/epos4_teleop/config/params.yaml))。真因は bus.yml の `2π/4096` (実機 1024 カウント) で、実車は指令の 1/4 速で走っていた — 07-29 に 5.0 + bus.yml 修正で根治 ([issue 07-07](../issue/closed/2026-07-07_wheel_odometry_encoder_scaling_4x.md))。`8ca003c` |
| **Nav2 自律走行の成立 (06-08〜06-12)** | 9 号館で slam_toolbox 地図を取得 → map_server + AMCL + Nav2 で 2D Pose Estimate → Nav2 Goal の自律移動に成功 (06-12)。「初期位置を指定するまで AMCL が動かず TF/costmap が warning」は lifecycle の仕様で不具合でなかった |
| ├─ Dockerfile に navigation2 / robot_localization、maps/ マウント | `ros-jazzy-navigation2` `nav2-bringup` `robot-localization` を追加 (現 [Dockerfile_main](../../docker/Dockerfile_main))、地図をホストに残すため compose に `./maps:/workspace/maps` ([docker-compose.yml](../../docker-compose.yml))、[.gitignore](../../.gitignore) に `maps/`。`53ba293` |
| ├─ nav2.launch.py + nav2_params.yaml 新設 (未検証) | map_server + amcl + Nav2 最小構成。同コミットで StarROS2 submodule を `external/` に追加 (現 [nav2.launch.py](../../ros2_ws_main/src/bringup/rerobot_bringup/launch/legacy/nav2.launch.py) — 10-08 に legacy へ、[nav2_params.yaml](../../ros2_ws_main/src/bringup/rerobot_bringup/config/nav2_params.yaml))。`fcba036` |
| ├─ keepout フィルタ追加 + bt_navigator plugin_lib_names 削除 | `filter_mask_server` / `costmap_filter_info_server` と両 costmap の `KeepoutFilter` (マスクは GIMP で my_map.pgm を編集)。`plugin_lib_names` を列挙すると Jazzy では既定ノードと二重登録で segfault するため削除。`9a158c0` |
| ├─ 全 C++ ソースに clang-format 適用 | controller / odometry / teleop / 旧 epos4_vel_ros2 の 5 ファイルを一括整形 ([.clang-format](../../.clang-format))。`9a158c0` |
| └─ RViz を nav2.rviz / slam.rviz に分割 (06-14) | 共通 rerobot.rviz では slam と nav2 の表示を使い分けられず、bringup は RViz を起動しない方針に。nav2.rviz は keepout マスク・costmap・経路・AMCL 粒子を表示 ([nav2.rviz](../../ros2_ws_main/src/bringup/rerobot_bringup/rviz/nav2.rviz), [slam.rviz](../../ros2_ws_slamtoolbox/src/rerobot_slamtoolbox/rviz/slam.rviz) — 07-26 に slamtoolbox ws へ)。`1cbf8d0` |
| **R-Fans-16 3D LiDAR の立ち上げ (06-11〜06-16)** | Sure-Star 公式 ROS1 ドライバ StarROS2 を ROS 2 に移植し、実機で 3D 点群を 20 Hz で出せるまで。設計 [features 06-13](../features/2026-06-13_rfans_driver_ros2_port.md)。このドライバは 08-14 に `surestar_rfans_ros2` へ置換され、現在は参照専用 (COLCON_IGNORE: [StarROS2](../../ros2_ws_main/src/drivers/StarROS2)) |
| ├─ ホスト側ネットワーク設定 | LiDAR 192.168.0.3 と通信するため有線 IF に `192.168.0.100/24` を手動付与 (再起動で消えるので NetworkManager 固定化が TODO)。コンテナは `network_mode: host` なのでそのまま使える (monthly 記載、コミットなし) |
| ├─ ROS1 → ROS2 移植 | SDK (`libstar.so`) は ROS 非依存で無改造、薄い ROS ラッパ層だけ移植。dynamic_reconfigure はパラメータコールバックで代替。Dockerfile に `libpcap-dev` 追加。`a4bf4e7` (submodule 側 `a0320ba`) |
| ├─ z=0 平面点群 / 「no matching device model」の解決 | 実機の `dataID=0x37` が LED 本数表にも SDK 縦角表にも未登録 → 16 本テーブルに追加 + `0x37→0x57` remap で縦角 ±15° が復活。[report 06-13 (z=0)](../report/2026-06-13_rfans_driver_dataid_0x37_z0_2d.md)。`a4bf4e7` |
| ├─ 更新 1〜2 Hz → 20 Hz の解決 | 点ごとに `rclcpp::spin_some()` を呼んでいた (1 フレーム ~15000 回) のを 1 スキャン 1 回に集約。[report 06-13 (low fps)](../report/2026-06-13_rfans_driver_low_fps_per_point_spin.md)。`a4bf4e7` |
| └─ 2D / 3D bringup の分離 (06-16) | `rerobot_bringup_2d/3d.launch.py` + `params_2d/3d.yaml` + `rerobot_2d/3d.urdf` に複製。08-10 に全部入り 1 本へ再統合され、ラッパは [launch/legacy/](../../ros2_ws_main/src/bringup/rerobot_bringup/launch/legacy/rerobot_bringup_3d.launch.py) に残置。「TF は OK だが RViz に点群が出ない」は未解決のまま (triage T12)。`e5695fb` |
| **Xbox ゲームパッド teleop (06-13)** | joy + teleop_twist_joy で `/cmd_vel` → `/robot_speed_cmd` に remap (LB=deadman, RB=turbo)。10-16 からは `/joy_vel` → twist_mux 経由に変更 |
| └─ joy_teleop.launch.py + joy_teleop.yaml | Dockerfile に `ros-jazzy-joy` `ros-jazzy-teleop-twist-joy` ([joy_teleop.launch.py](../../ros2_ws_main/src/bringup/rerobot_bringup/launch/joy_teleop.launch.py), [joy_teleop.yaml](../../ros2_ws_main/src/bringup/rerobot_bringup/config/joy_teleop.yaml))。`e87c746` |
| **未解決のまま月をまたいだ調査 (コミットなし)** | monthly の記載から。07-07 の [TODO トリアージ](../issue/2026-07-07_monthly_2026_6_todo_triage.md) で T1〜T14 に整理 |
