# 照合地図 p16 vs p100 (画素点数しきい値) の同一 bag A/B — 5 号館 2 bag

**結論 (critic 査読後の表現):** 5 号館コースの 2 bag (11-01 2114、11-05 1903) を同じ harness で再生したところ、地図作成走行と同じ車線を走る区間では、p100 は次のように改善した。
- 横ずれの中央値: **0.14〜0.16 → 0.05〜0.08 m**
- 横ずれの p90: **0.37〜0.44 → 0.19〜0.20 m**
- AMCL 自己申告の σxy: **0.6 → 0.3 m**

物差しを 3 種類に替えても順位は変わらない (§6)。体感の「p16 より安定」はこの横ずれと粒子雲の縮みで説明できる。植え込み通路 (2114 の 400〜500 / 900〜1000 s の場所) も 0.24〜0.33 → 0.05〜0.08 m と、悪化せず改善している。

**ただし:**
- (1) **yaw は一様には改善しない。** 地図作成走行の車線から 2 m 以上外れた区間 (1903 の 1800 s 以降、208 スキャン) では、p100 の yaw は **2.8/3.3°**、p16 は **0.6〜1.2/1.0〜1.7°** で p100 が悪い。
- (2) σxy の半減は、そのまま精度 2 倍を意味しない。誤差 hypot(横, 前後) の中央値は約 0.6 倍 (0.38 → 0.23 m、1903 は 0.41 → 0.23 m) に減ったが、σ と誤差の相関は 0.38 → 0.15 に落ちた。
- (3) AMCL 再生は事実上決定的なので、条件ごとの独立な試行は実質 1 本ずつ。
- (4) 機構は分離できていない。帯が薄くなる・遠方の特徴が落ちる・点数の少ない雑物が落ちる、の 3 つが同時に起きている。
- (5) つくば本番地図に「同じ 100」を当てるのは保留。しきい値が絶対点数なので、地図 bag の滞在時間が違えば意味が変わる。比率しきい値か最近点方式の地図と比べてから決める (§8)。

## 2. 方法

- 再生: `bags/exp/2026-11-01_loc_res/replay_amcl.sh` (PREWARM 付き。bag の map→odom を除去し、初期姿勢は bag の /initialpose を odom 補正つきで送る)。AMCL パラメータは `amcl_live_scanall.yaml` (現行 amcl.yaml + scan_all 2000 本)。bag A は `START=20`。bag B は 2 回目の /initialpose (42.3 s) を使うため `START=40`。2 bag × 2 地図 × 2 本を直列で回した。
- 採点: `wobble_ref.py`。`bags/exp/2026-10-16_loc_wobble/wobble.py` のコピーで、`--only_ref` を付けると再生姿勢 (ref) だけを採点する。ref の計算式は元と同一。各スキャン (1 s ごと、30 m 以内の 400 点) を推定姿勢に置き、**p16 地図**の距離場に最もよく乗る微小補正を探して、その補正を横 / 前後 / yaw に分ける。物差しは両条件とも p16。T > 60 s の行だけを使う。
- 集計: `agg.py` → `agg.json` / `agg_final.log`。各指標の定義は次のとおり。
  - σxy: `/amcl_pose` の √(cxx+cyy)。
  - 補正の跳び: AMCL の更新ごとに、ロボット位置で map→odom の補正が何 m 動いたか (|mo_k∘o − mo_{k−1}∘o|)。map→odom の並進をそのまま比べると、odom 原点が遠いとき yaw の補正で水増しされるので使わない。
  - 地図に乗った点の割合: scan_all の全端点 (1〜100 m) を推定姿勢に置き、占有から 0.1 m 以内に落ちた割合。
  - 植え込み通路: 2114 の T 400〜500 / 900〜1000 s の当てはめ軌跡から 3 m 以内の場所。1903 にも同じ場所で当てる。
- 車線距離別の集計: `lane.py`。10-09 の GLIM 軌跡 (`traj_lidar.txt`) からの距離で行を分ける。
- 台地幅: `bags/exp/2026-11-03_slamtoolbox_2d/compare.py` を `SECOND_POSE=fit SLAM_MAP=<p100> TAG=_p100` で実行 (2114、6 時刻)。
- ⚠️ **再生の巻き添え停止**: 同じコンテナの別作業 `bags/tools/2026-11-02_person_stop/replay_plan/run_plan.sh` が `pkill -9 -f 'bag play'` を打つため、p16 r1 の 2 本が途中で止まった (1284/1420 s、1178/2017 s)。`queue3.sh` が末尾まで届いていない run を検出し、`<run>_trunc1` に退避して再実行した。表の数値はすべて完走した run のもの。

## 6. critic 査読 (2026-11-06) と棄却できていない代替仮説

critic の判定は「弱める (部分的に維持)」。自分で確かめた点と、残った点は次のとおり。

- **物差しへの依存は棄却**: 物差しを p16 / 随伴者の筋を除いた p16 / p100 の 3 種類に替えて、2114 を採点し直した。結果は p16 r2 の横が 0.155〜0.160、p100 r1 の横が 0.068〜0.079 で、順位も値もほぼ同じ。推定姿勢のコストが最良点とほぼ同じになる (平らな谷で argmin が任意になる) スキャンは 0〜1 %。
- **「随伴者の筋が消えたから良くなった」は棄却**: 10-09 軌跡から 0〜0.3 m にある p16 の占有 209 m² のうち、**69 % は p100 に残っている** (p100 の占有の約 15 % が筋)。筋を除いた物差しでも差は変わらない。逆向きのリスクとして、随伴者がいない日や他チームのロボットが後ろにいる日には、筋が誤照合の的になり得る (`docs/issue/2026-11-04_companion_streak_in_loc_map.md`)。
- **σxy**: 誤差 e = hypot(横, 前後) が σxy を超える割合は、2114 で 0.09 → 0.28 に増えた。corr(e, σ) は 0.38 → 0.15 (1903 の p100 は −0.06)。σ の縮みは、誤差の縮みより速い。
- **棄却できない代替仮説**:
  1. 改善の正体は「帯が薄い」ではなく、「遠方の特徴と点数の少ない雑物が一緒に落ちた」ことかもしれない。しきい値 1 本の操作では分離できない。
  2. p100 は地図作成走行の車線に偏った地図で、車線上でだけ勝つのかもしれない。§4.3 の車線外の yaw 悪化はこの仮説を支持する方向。
  3. 粒子雲が細くなったぶん、大きく外れた後の回復が弱くなっているかもしれない (recovery 無効)。今回の 2 bag には大きな外乱が無く、検定できていない。
- **1903 bag は p100 の閉ループで走った車線**なので、選択効果で p100 に有利な可能性がある。中立に近い主証拠は 2114 (p16 で走った bag。それでも p100 が勝つ)。
- 前後方向 (0.2〜0.45 m) は、物差し側の当てはめが弱い方向。改善の主張は横と σ に限る。

## 7. 次の実験 (未実施、安い順)

1. **車線外の弱点の確定**: 1903 を 1750 s から約 270 s 再生する。初期姿勢を {0、横 ±0.3 m、yaw ±3°} の 5 通りに振り、p16 / p100 で計 10 本 (約 1 時間)。p100 の yaw が 5 本とも 2° を超えるなら「車線外で弱い」が確定する。r1/r2 が決定的で取れていない run 間のノイズ床も同時に取れる。
2. **回復能力**: 2114 の 400 s と 950 s (植え込み通路) で、初期姿勢を横 ±0.5/±1.0 m、yaw ±5° ずらして再開し、両地図で 30 s 後に収束しているかを見る。
3. **機構の分離**: 帯だけを薄くして遠方は残す地図 (最近点 / 観測機会に対する比率しきい値) と、p16 から 15 m 超の占有だけを消した地図を作り、2114 で A/B する。
4. bag を増やす: 11-03 の 2 本 (5 号館、別日) で同じ A/B。

## 8. つくば本番地図への展開 (条件付きの手順)

現行のつくば loc 地図は `maps/2d/glim/2026-10-03_1126_tsukuba_composite/raw_traj/0.3-100.0_r100/` (4 bag 合成、scans_used 50707、`--min/max_points_in_pix 12 20`、占有 10633 m²)。5 号館の地図 bag は 11641 スキャンで、画素あたりの点数は「滞在時間 × 通過回数 × 距離」で決まる。そのため **5 号館の 100 がつくばでも同じ意味になる保証は無い**。つくばは広場・遠方特徴の区間が多く、§4.3 の車線外の弱点が出やすい。作り直すなら、§7-1 で車線外の挙動を確認してから、次の順で進める。

1. 生 bag を Drive から戻す。`bags/raw/2026-10-03_1126_tsukuba_seg{1..4}` はローカルから削除済みで、GLIM dump `bags/glim/2026-10-03_1126_tsukuba_dump/composite_4map` は残っている。
2. しきい値を数点 (例: 48/56、96/104) にして生成する (main コンテナ内、1 本ずつ — 16 GB 機)。

     /workspace/bags/raw/2026-10-03_1126_tsukuba_seg1,/workspace/bags/raw/2026-10-03_1126_tsukuba_seg2,/workspace/bags/raw/2026-10-03_1126_tsukuba_seg3,/workspace/bags/raw/2026-10-03_1126_tsukuba_seg4 \

3. 占有面積の比を見る (5 号館は p100/p16 = 0.28)。広場・遠方特徴の区間で、壁が消えすぎていないかを目視する。

5. 使うときは、auto_run の `loc_band:=0.3-100.0_r100_p100` で指定する (既定 `0.3-100.0_r100` は変えない)。
