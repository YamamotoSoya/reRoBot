# ハードウェア仕様 (rev.1)

このドキュメントの結線情報は、すべて KiCad の PCB ネットリスト
(`PCB/BNO086_ROS2Board/BNO086_ROS2Board.kicad_pcb`) から抽出したものです。
`BNO086_ROS2Board.ioc` ではなく **こちらが正** です (理由は末尾の「.ioc との差異」参照)。

## 構成

| 部品 | 型番 | 役割 |
|---|---|---|
| U3 | STM32F042C6U6 (UFQFPN48) | MCU。Flash 32 KiB / RAM 6 KiB |
| U4 | BNO086 | 9軸 IMU + センサフュージョン |
| U5 | SOT-23-8 CANトランシーバ | CAN (J5)。※後述の注意あり |
| U2 | TLV74033PDBVR | 3.3 V LDO |
| IC1 | NJW1933F1 | 降圧DC-DC (VIN → 5 V) |
| Y2 | 8 MHz | STM32 HSE。USB に必須 |
| Y1 | 32.768 kHz | BNO086 用 |

## ピンアサイン

### BNO086 (SPI)

| STM32 | ピン番号 | ネット | BNO086 | 方向 | 備考 |
|---|---|---|---|---|---|
| PA5  | 15 | `IMU_SCK`  | 19 (SCLK) | OUT | SPI1_SCK |
| PA6  | 16 | `IMU_MISO` | 20 (MISO) | IN  | SPI1_MISO |
| PA7  | 17 | `IMU_MOSI` | 17 (MOSI) | OUT | SPI1_MOSI |
| PB10 | 21 | `IMU_CS`   | 18 (CSN)  | OUT | ソフトNSS、負論理 |
| PB2  | 20 | `IMU_INT`  | 14 (H_INTN) | IN | 負論理。データ有りでLow |
| PA4  | 14 | `IMU_RST`  | 11 (NRST) | OUT | 負論理。R5 10k プルアップ |
| PB0  | 18 | `IMU_WAKE` | 6 (PS0/H_WAKEN) | OUT | R6 10k プルアップ、JP1 |
| PB1  | 19 | `IMU_BOOT` | 4 (BOOTN) | OUT | R8 10k プルアップ。Highで通常起動 |

SPI は **モード3 (CPOL=1 / CPHA=1)**、MSBファースト、最大 3 MHz。
ファームは PCLK 48 MHz / 16 = 3.0 MHz で駆動しています。

### 実装角度 (重要)

**U4 (BNO086) は基板上で 180° 回転して実装されています。**

```
U4  BNO086  位置=(154.05, 103.69)  回転=180°
```

したがってセンサの軸と基板の軸は次の関係になります。

| センサ | 基板 |
|---|---|
| +X | **−X** |
| +Y | **−Y** |
| +Z | +Z (一致) |

ROS 2 ドライバはこれを `mount_yaw_deg` パラメータ (既定 `180.0`) で補正し、
`/imu/data` を**基板座標系**で publish します。`frame_id` (`imu_link`) は
基板の座標系を指します。

センサ生の座標系がほしい場合は `mount_yaw_deg: 0.0` にしてください。
基板を別の向きで機体に取り付ける場合は、この値ではなく機体側の
static transform で表現するのが ROS の作法です。

### プロトコル選択ストラップ (重要)

BNO086 は NRST の立ち上がりで PS1/PS0 をサンプリングし、通信方式を決めます。

| PS1 | PS0 | プロトコル |
|---|---|---|
| 0 | 0 | I2C |
| 0 | 1 | UART |
| 1 | 0 | UART-RVC |
| 1 | 1 | **SPI** ← 本基板 |

> **重要** BNO08X データシート (1.16版, 1.2.4 / Figure 1-20) より、SPI を選ぶには
> **PS1 と PS0 の両方が、NRST 解除前から最初の H_INTN アサートまで High** で
> なければなりません。PS0 を Low にすると UART-RVC で起動し、SPI には一切
> 応答しなくなります (実機で確認済み)。

- **PS1** (U4 pin5) … R7 で 3.3 V にプルアップ。`JP2` を GND に短絡すると 0。
- **PS0** (U4 pin6) … R6 でプルアップ、かつ PB0 が直接ドライブ。`JP1` で GND 短絡可。

したがって **JP1 / JP2 はどちらもオープンのまま** にしてください。
ファームウェアは PB0 を High に保ったままリセットを解除して SPI を選択し、
起動後は同じピンを H_WAKEN (負論理、アイドル High) として使います。
JP1 を短絡すると PB0 が GND と衝突するので絶対に閉じないでください。

### ホストインタフェース

| 信号 | STM32 | コネクタ |
|---|---|---|
| USB D− / D+ | PA11 / PA12 | J1 (USB Type-C) |
| USART1 TX / RX | PA9 / PA10 | J4 pin4 / pin3 (JST SH 4pin) |
| SWDIO / SWCLK | PA13 / PA14 | J3 (2×3 1.00 mm) |
| CAN RX / TX | PB8 / PB9 | U5 → J5 (JST SH 3pin) |

USB は STM32F042 内蔵の D+ プルアップを使うため外付け抵抗はありません
(基板上にも実装されていません)。

### LED / その他

| 信号 | STM32 | 論理 |
|---|---|---|
| `LED1` | PB12 | 正論理 (アノード側がMCU、R13 5.1k → GND) |
| `LED2` | PB13 | 正論理 |
| `BOOT0` | pin44 | R11 10k → GND。S2 押下で High |
| `NRST` | pin7 | R10 10k プルアップ、S1 |

**S2 (BOOT) はファームウェアから読めません。** 48ピンパッケージの STM32F042C6 では
44番ピンは BOOT0 専用ピンで GPIO ではなく、レベルを読み出すレジスタが存在しません
(20ピン品なら `nBOOT_SEL` で PB8 と兼用にできますが、48ピン品には適用不可)。
S2 はリセット時にブート元を選ぶためだけのものです。

IMU をリセットしたい場合:

- **S1 (RESET)** … MCU が再起動して `bno08x_reset()` が走るので実質 IMU リセットに
  なります。USB は一度切れますが、ROS 2 ノードが自動で再接続します。
- **ROS 2 サービス** … `ros2 service call /bno086_imu_driver/reset` なら MCU を
  落とさず IMU だけを入れ直せます。

物理ボタンで IMU だけをリセットしたい場合は、未使用ピン (PA0, PA1, PA8, PA15,
PB3〜PB7, PB11, PB14, PB15) のいずれかにスイッチを追加してください。

ファームウェアでの意味:

- LED1 … 1 Hz 点滅 = 動作中 (ハートビート)
- LED2 … 点灯 = BNO086 が応答しストリーミング中
- 両方が高速点滅 = `board_error()` (致命的エラー)

### 電源

```
J2 (VIN) ──┬─ JP3 ─→ IC1 NJW1933 降圧 ─→ +5V
           └─ JP3 ─→ 直接 +5V
USB VBUS ──── D1 ──────────────────────→ +5V
                                          └→ U2 TLV74033 → +3V3
```

`JP3` は VIN を DC-DC 経由 (12 V 系) にするか 5 V 直結にするかの選択です。
DC-DC の出力電圧は R15 39k / R16 12k の分圧で決まります。

## 未使用・未実装

- **USART2 (PA2 / PA3)** … ネットは存在しますがコネクタに出ていません。
- **CAN** … ハードウェアは実装済みですが、**ファームウェアは未実装** です。

## 発注前に確認したい点

### 1. CAN トランシーバ (U5) の Vio

ネットリスト上、U5 の電源は次のようになっています。

| ピン | シンボル名 | 接続先 |
|---|---|---|
| 3 | VCC | **+3V3** |
| 5 | Vio | **+5V** |
| 8 | STB | GND (常時ノーマルモード) |

`Vio` はロジック側 (TXD/RXD) の基準電圧です。STM32 は 3.3 V でドライブするため、
Vio = 5 V だと TXD の Highしきい値 (概ね 0.7×Vio ≒ 3.5 V) に届かず、
CAN が送信できない可能性があります。**Vio は +3V3 に接続するのが本来の意図**
ではないでしょうか。実装部品のデータシートで確認をおすすめします。

なお CAN ファームは未実装なので、当面この配線は動作に影響しません。

### 2. `.ioc` との差異

`BNO086_ROS2Board.ioc` は PCB と一致していません。CubeMX で再生成する場合は
先に修正してください (本リポジトリのファームウェアは CubeMX 生成に依存しない
ため、`.ioc` は参考情報の位置づけです)。

| 項目 | .ioc | 実際の基板 |
|---|---|---|
| IMU 割り込み | `PF11` を GPIO_EXTI11 に設定 | **PB2**。PF11 は48ピン品に存在しない |
| PB2 | GPIO_Output | 割り込み入力 |
| LED1 / LED2 | 記載なし | PB12 / PB13 |
| クロック | PLL 16 MHz / SYSCLK 8 MHz | USB のため **48 MHz** が必須 |

クロックについては、USB を使う以上 HSE 8 MHz × PLL6 = 48 MHz 以外の選択肢が
ありません (STM32F0 の USB には分周器がないため)。
